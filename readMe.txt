# XML Parser - Group Zelda

## How to Use:
1. Open terminal and navigate to project folder.
2. Run the parser with:
   java -jar Parser.jar <filename>

Example:
   java -jar Parser.jar sample1.xml

## Notes:
- Ensure the XML file is in the same directory or provide full path.
- Errors will be printed line-by-line for malformed XML.
- A "well-formed" message will appear if valid.

## Requirements:
- Java 8+
- No external libraries used for data structure implementations.
